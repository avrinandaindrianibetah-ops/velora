# VELORA (Aplikasi Monitoring Kehadiran Mahasiswa)

## Tujuan Proyek
Aplikasi mobile berbasis Flutter untuk memantau kehadiran mahasiswa dengan sistem anti-kecurangan (*Hardware Binding*) dan ketahanan jaringan (*Offline-First*).

## Teknologi yang Digunakan
* Framework: Flutter (Dart)
* Backend: Firebase (Authentication, Cloud Firestore, FCM)
* Local Storage: SQLite / Hive

## Cara Menjalankan Proyek
1. Clone repository ini: `git clone https://github.com/avrinandaindrianibetah-ops/velora.git`
2. Masuk ke direktori: `cd velora`
3. Ambil dependencies: `flutter pub get`
4. Jalankan aplikasi: `flutter run`
